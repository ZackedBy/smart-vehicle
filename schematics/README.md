Edit the `.drawio` files at https://app.diagrams.net/.

To export a JPEG that matches the ones in this folder, set a dark canvas, then File -> Export as -> JPEG, border width 20, appearance Dark.

The Mega pin numbers in `firmware/mega/include/config.hpp` follow `mega/mega_schematic.jpg`. Check the motor nets against the DRV8835 before rewiring; those lines on the drawing are the ones most likely to be wrong.
